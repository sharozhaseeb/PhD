Setup

Replay real optimization commits, with full validation as the oracle

How

  • Mine historical commits with a frozen rule; replay them one after another on one base tree
  • At every state, run FULL: build, all tests, all benchmarks
  • Score each reduced arm by what FULL catches; asv verdict rule plus a pre-registered 1 + 3σ noise floor
  • Rules frozen and hashed before runs; every number traced to a raw file
