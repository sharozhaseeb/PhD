## 2. Design

**Format.** One private claude.ai artifact (single HTML page, no external scripts, inline SVG + CSS animation, light and dark themes via `prefers-color-scheme` / CSS variables). Source copy: `pm/advisor-kb/kb.html`. Length target: ~10 screens; each section = takeaway sentence → diagram → 2–4 lines of text → a "numbers & sources" strip.

**Global rules on the page.**
- Every number has a source tag (`NUM: macro`, `F: id`, `R: §`) in the strip; numbers.tex wins.
- Status chips on every claim: **measured**, **computed** (no timing), **inferred**, **planned**.
- A one-line disclosure banner near the top: edit labels are from LLM agents (two blind raters + adjudicator, same model family, κ 0.948 inflated); the validation method has no learned component.
- Scope chip on every finding: "networkx, one project, one machine".
