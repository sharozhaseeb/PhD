# Paper writing for Study 1 (04-paper/)

This skill encodes the W7 writing toolkit (`pm/writing-toolkit.md`). The two failure modes that would sink this paper are (1) a number that does not trace to a raw file and (2) a citation that was never read. Everything below exists to prevent those two, plus overclaiming.

## Files

| Path (under 04-paper/) | What it is | Edit by hand? |
|---|---|---|
| `main.tex`, `sections/*.tex` | the paper | yes |
| `refs.bib` | only entries from `01-literature/references.bib` or a read source; each has a `note` with its verification status | yes, carefully |
| `generated/numbers.tex` | every number in the text, as a macro, each with a comment naming its raw file | **no**: `python scripts/make_all.py` |
| `figures/*.pdf` | generated plots | **no**: `make_all.py` |
| `data-manifest.yaml` | every raw input path plus sha256 | regenerated by `make_all.py --manifest` |
| `scripts/check.py` | fails on a stray digit in prose, a macro that disagrees with `results.md`, an undefined macro or cite key | run before every review |

## The loop (toolkit §4.6), per section

1. **Draft** with template 4.1 (`references/4.1-section-drafting.md`): evidence first (macro, value, quote from results.md), then LaTeX, then a self-check that retracts any claim without evidence.
2. **Check**: `python scripts/make_all.py && python scripts/check.py`. Fix until clean. A number that has no macro yet goes into `make_all.py` (computed from the raw file), never typed into prose.
3. **Critic pass** on the section (a fresh subagent; give it the section and `generated/numbers.tex`).
4. **Hostile reviewer** on the whole paper at outline, mid-draft and full-draft stages: the `hostile-reviewer` agent (`../../agents/hostile-reviewer.md`, read-only), template 4.2. Give it the paper and the macros only, not our threats table or notes (reviewer echo, §5.6).
5. **Empirical-Standards pass** once the draft is full: template 4.3, with the standards text fetched, never paraphrased from memory.
6. **Advisor-persona review** (TPM §5), then revise. Keep draft, review and revision as separate calls.

Related work uses template 4.4 (sentence → cite key → quote). Threats use template 4.5 (Wohlin order: construct, internal, external, conclusion; specific threats only, Verdecchia et al. 2023).

## Rules that apply to every sentence

- **Numbers**: only macros. Ranges stay ranges (both ends are macros); never a point value for something measured as a range (R1 8–28×, drift).
- **Scope**: every result says "on networkx" (or "on bottleneck") until the multi-project replication lands. Say "replayed edit sequence", never "iterative session".
- **Novelty**: "not found in our recorded searches", quoting the search record in `01-literature/`. No "first", "novel", "gap", "most"; "significant" only with the test named.
- **Statistics**: performance verdicts use the exact two-sided Mann-Whitney test (results.md "Exact-test recompute"); proportions get Wilson 95 % CIs.
- **Pending results**: write `\TODO{<exactly which result, from which experiment>}`. Never fill a gap with a plausible number.
- **Citations**: never from memory. A key not in `refs.bib` becomes `\citeneeded{topic}` and goes on the W1 list. Snippet-only DOIs stay marked `[S]` in the bib note.
- **Negative results** are reported plainly (A4 policy, no accumulation effect).
- **No AI in the method.** AI assistance in tooling and writing is disclosed per the venue policy.

The full list of things to avoid and the 16-item must-not-claim list are in `references/avoid-and-must-not-claim.md`. Read it before drafting or reviewing any claim-bearing section (abstract, intro, results, discussion, conclusion).
