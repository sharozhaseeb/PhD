# Audit Data

These machine-readable files are inputs to the local research audit harness.

- `project.json`: project metadata and required protocol flags
- `claims.csv`: claims and evidence status
- `hypotheses.csv`: candidate hypotheses, rivals, and falsification tests
- `nearest_work.csv`: closest-paper comparison matrix
- `search_log.csv`: reproducible novelty-search ledger
- `experiments.csv`: experiment and multiple-testing registry
- `risks.csv`: validity and feasibility risk register

Blank or unresolved entries are intentional audit findings, not errors to conceal.
