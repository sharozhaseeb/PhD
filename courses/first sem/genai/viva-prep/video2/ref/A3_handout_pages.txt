Objective  
In this assignment your group will implement and compare Full Fine-Tuning, LoRA, QLoRA and IA³ for  
Urdu or Roman Urdu text classification, and present the comparison in a short report. Your  
comparison should answer these questions:  
• RQ1. How do the four methods trade off accuracy against trainable parameters, training time  
and GPU memory for an Urdu or Roman Urdu task?  
• RQ2. How well do the tokenizers of multilingual models handle Urdu and Roman Urdu, and  
does this affect accuracy and cost?  
• RQ3. Which method degrades least when labelled data is scarce?

Part 1: Data and Tokenizer Analysis (10%)  
• Load your dataset, remove empty rows and exact duplicates, and create a stratified 70/15/15  
train, validation and test split (Track 2: use the given splits). Report the class distribution in a  
table.  
• Normalise the text: remove URLs and user mentions, and for Urdu script unify character  
variants (for example, Arabic and Urdu forms of yeh and kaf). Describe every cleaning step in  
the report.  
• Tokenizer analysis (RQ2): for both models, report the fertility (average subword tokens per  
word), the share of texts truncated at your chosen max_length, and the unknown-token rate.  
Choose max_length from the 95th percentile of token lengths and justify it.  
Part 2: Implementation (25%)  
Fine-tune both models with all four methods, using the Hugging Face Trainer and the PEFT 
library: • Full Fine-Tuning, as the accuracy and cost baseline.  
• LoRA, with task_type="SEQ_CLS" so that the classification head is also trained. 
• QLoRA: load the base model in 4-bit NF4 with BitsAndBytesConfig, call   
prepare_model_for_kbit_training, then add LoRA. The T4 does not support BF16 well, so  
use bnb_4bit_compute_dtype=torch.float16.  
• IA³ (Infused Adapter by Inhibiting and Amplifying Inner Activations; Liu et al., Few-Shot  
Parameter-Efficient Fine-Tuning is Better and Cheaper than In-Context Learning, NeurIPS 2022):  
instead of adding new matrices, IA³ learns three vectors per layer that rescale the keys, the  
values and the feed-forward activations element by element (for example, Kʹ = lk ⊙ K). The  
vectors start at 1, so training begins from the pre-trained model; values above 1 amplify a

feature and values below 1 inhibit it. It trains only about 0.05% of the parameters and can be  
merged into the weights after training. Use IA3Config in PEFT, and print the model to find 
the  correct module names for each architecture.  
Measure in every run: macro-F1 (the main metric, since the classes are imbalanced), accuracy,  
training time, peak GPU memory using torch.cuda.max_memory_allocated(), and the number of  
trainable parameters.
