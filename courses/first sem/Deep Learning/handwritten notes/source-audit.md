## Source corrections and safeguards

1. **Threshold convention:** sources alternate `>=` and `>`. Define the chosen step function explicitly and use half-integer thresholds where practical. A threshold T becomes bias −T. For signed-label perceptron learning specify the zero-margin/tie update rule.
2. **Parity/DNF:** L2 80–87 counts 2^(N−1) minterms for the lecture's DNF construction, plus one output; this is not a universal lower bound for arbitrary threshold MLPs. Three-perceptron XOR gives 3(N−1) total units; balanced construction depth is 2 ceil(log2 N), or exactly 2 log2 N for powers of two, counting computational layers only. A skip-connected two-unit XOR has a different connection count; do not mix architectures. Restricted Boolean AND/OR/NOT circuit results are not arbitrary threshold-network results.
3. **Universal approximation:** L2 113–119 loosely says any boundary/function can be modeled. State approximation under suitable activation/domain assumptions, sufficient width, finite requested precision; capacity does not guarantee learnability, exact finite representation, or generalization.
4. **Derivative tests:** L3 123–132 should distinguish stationary points from extrema. Positive-definite Hessian at stationary point suffices for a strict local minimum; semidefinite cases can be inconclusive. Zero second derivative need not mean inflection; x^4 is a counterexample. Zero gradient need not be a minimum.
5. **Convergence claims:** L3 143 and L5 56/124 overstate convergence. Convexity requires suitable smoothness/steps; nonconvex GD/SGD need not reach a local minimum and can stagnate at stationary points or diverge. Robbins–Monro sums Ση=∞, Ση²<∞ are learning-rate conditions under additional objective/noise assumptions, not stand-alone global guarantees. η~1/k is fastest boundary exponent in that family, not universally optimal.
6. **L4 p5 bias update typo:** bias update must use its own bias gradient, not the displayed W-gradient. Define gradients as sums or means once and average exactly once.
7. **L3 p156 ReLU corner:** derivative at zero is undefined mathematically; chosen 0 (or other subgradient) is a convention. Softplus derivative is sigmoid; sigmoid derivative uses that neuron's own activation.
8. **Backprop:** handout equations and source-to-target indexing are mathematically consistent. Preserve w_(i,j) from previous-layer i to current-layer j; matrix W is previous-width × next-width under that convention, with z=W^T y+b for columns. Sum all outgoing paths at hidden nodes. Compute all deltas with the unchanged forward-pass weights, then update together. The output δ=y−t shortcut is sigmoid+BCE only; half-SSE includes sigmoid derivative.
9. **Backprop versus optimization:** L4 8–29 ‘backprop fails’ examples concern optimizer/objective/classification mismatch. Backprop is the derivative algorithm and is not itself a low-variance estimator or a guaranteed classifier. Bias/variance depends on the model, objective, regularization and data, not a universal property of backprop versus perceptron.
10. **Quadratic stability:** for E=.5 a w²+bw+c, a>0, error multiplier is 1−ηa. Require 0<η<2/a; η=1/a reaches optimum in one step; η=2/a gives undamped oscillation except at optimum. Multivariate SPD bound 0<η<2/λmax; ratio λmax/λmin explains slow learning. Local Hessian inverse is not universally an optimal scalar learning rate for generic convex functions. Newton may not descend with indefinite Hessian and may require damping.
11. **RProp variants:** source 68–72 reverses/undoes the previous move on a sign change. Explicitly state the illustrated rollback variant, shrink the positive step magnitude, handle zero derivative and cap/floor. Do not silently substitute iRprop− while describing the source's backtracking. QuickProp is only named, so a short label suffices.
12. **Momentum/Nesterov:** distinguish velocity-as-step v=βv−ηg, w+=v from EMA m=βm+(1−β)g, w−=ηm. Either is valid with stated convention; equal η values yield different steps. Nesterov evaluates at w+βv; do not add βv twice. Keep momentum/moment state across batches.
13. **Sampling:** unbiased empirical loss statement is for a fixed W and iid data (or gradients for uniform sample selection at fixed W). The minimized training loss is generally optimistically biased. Variance Var(mean)=σ²/B assumes independent samples; without-replacement finite-population correction differs. Last partial batch divides by its actual size. Shuffle-per-epoch gradients need qualified conditional-unbiasedness wording.
14. **Adaptive optimizer notation:** L5 p115 means squared gradient, not second derivative. RMSProp source places ε inside the square root; use a declared consistent convention in formula and substitution. Adam source also uses ε inside; standard outside-root variant may be taught only if labeled. Bias-correction exponent uses update count starting at1. L5 p123 claims adaptive methods have no explicit learning rate, contradicted by its own η values; they still require hyperparameters.
15. **L2 regularization:** source objective uses mean data loss + λ/2 Σ||W||², so penalty gradient is λW and vanilla update shrinkage (1−ηλ). State bias inclusion/exclusion, do not add another dataset-size factor unless objective defines it. L2 penalty under adaptive optimizers is not automatically decoupled AdamW. Greater depth/smaller weights can help but do not guarantee smoothness or generalization.
16. **Dropout:** source α is keep probability, dropout rate1−α. Classic train m⊙h, test αh; inverted train m⊙h/α, test h. Dropped-unit gradient is0, retained gradient gets matching scaling. Scaling outgoing weights applies only from masked nonconstant units; bias is not arbitrarily scaled. L5 p157 ‘all weights’ is too broad. Exact expected activation for fixed upstream h does not imply exact whole nonlinear-network ensemble mean; test scaling is an approximation. Masks share weights, so dropout is not independent bagged training.
17. **Clipping:** L5 p161 caps only positive derivative; correct coordinate clipping to [−c,c]. Norm clipping scales entire vector by min(1,c/||g||). These are different rules and need separately labeled numericals. Threshold5 is an example, not universal.
18. **Validation/preprocessing:** fit normalization statistics on training data only, reuse for validation/test. Input standardization is not identical to trainable batch normalization. Early stopping retains best validation checkpoint, not necessarily last epoch. Tune on validation, reserve test for final evaluation. Augmentation must preserve labels; geometry transforms may invalidate digit labels. Identical neurons remain symmetric under identical deterministic updates; independently sampled dropout can break that symmetry, so qualify the blanket initialization claim.

## Numerical production rules

- Use natural logs; show prediction, residual or delta, loss reduction, local derivatives, averaged gradients, update and interpreted result. Round only after calculation.
- Reuse the same small network across forward/output/hidden pages, while repeating enough givens to read each independently. Include a genuine branching-path sum so hidden backprop is not taught as a single-chain multiplication.
- Prefer one full worked numerical per page to several truncated exercises. Where two methods are compared, use identical givens and name convention differences.
