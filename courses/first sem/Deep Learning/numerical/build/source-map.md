## Visual verification and especially important source discrepancies

Inspected source renders: L3 pp41 and156; L4 pp57 and71; L5 pp56,58,103,106,116,121,137,138,153,155,156,163. Existing source renders are under `tmp/course-update-20260916/`, `tmp/deep-learning-lecture-review/`, and `tmp/deep-learning-l4-*`; a new source-only render of L3 p41 is `tmp/source-map-perceptron.png`.

1. **ReLU at zero really differs across the supplied sources.** L3 p156 explicitly uses z>=0 for derivative 1; Assignment p2 says 1 if z>0, else 0. Use A's 0 convention in assignment-aligned network work and label it. Away from zero, formulas agree.
2. **Assignment batch notation is shorthand.** Keep per-example loss and delta separate, then average once. Defining delta as derivative of already averaged objective and averaging again gives an unwanted 1/N^2.
3. **RProp p71 bounds need magnitude interpretation.** For a negative signed step, min(alpha*Delta,positive max) does not impose the intended magnitude cap. Explain positive s and signed Delta=sign(prevD)*s while preserving rollback/retained derivative logic.
4. **Both L5 optimizer radicals include epsilon.** This was visually verified, not inferred from text extraction. A demo with epsilon=0 hides the difference; include one small positive-epsilon check or explicitly explain both denominators.
5. **L2 p138 has a visible coefficient mismatch.** The preceding line has -eta*lambda*W; the boxed line changes to (1-lambda)W. Show the correct derivation from p137 and explain the shorthand instead of copying inconsistency.
6. **Dropout expectation is an approximation for nonlinear networks.** Source p155 uses approximately equal; do not change it to equality. p153 also visually mixes a constant-input notation and separate +b; in the example count bias exactly once.
7. **Initialization is a named list, not derivations.** If optional scales are included, specify Xavier normal variance 2/(fan_in+fan_out) or He normal variance 2/fan_in and distinguish variance from SD. Do not imply all library variants/gains have the same formula.
